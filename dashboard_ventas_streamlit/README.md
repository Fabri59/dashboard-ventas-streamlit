# Dashboard interactivo de ventas

Proyecto académico de visualización de datos desarrollado con Python, Streamlit, Pandas y Plotly.

## Funcionalidades
- Indicadores de ventas totales, unidades, promedio y pedidos.
- Filtro por rango de fechas y categoría.
- Gráfico de ventas por categoría.
- Evolución mensual de ventas.
- Productos con mayores ventas.
- Tabla de registros filtrados.

## Ejecutar localmente
1. Instala Python 3.10 o superior.
2. Instala las dependencias:
   ```bash
   pip install -r requirements.txt
   ```
3. Ejecuta la aplicación:
   ```bash
   streamlit run app.py
   ```

## Despliegue
Sube el contenido de este repositorio a GitHub. Luego entra a https://share.streamlit.io/, conecta GitHub, selecciona el repositorio y el archivo `app.py`. Streamlit Community Cloud publicará la aplicación y te dará una URL.

Al actualizar y subir cambios a la rama conectada, Streamlit Community Cloud puede volver a desplegar la aplicación automáticamente.

## Datos
`data/sales.csv` contiene datos de ejemplo creados para fines académicos; no representan ventas reales.
